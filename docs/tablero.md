# Tablero de tareas del equipo - guia clic por clic
## Infeccion: Escape del Carmen (Sprint 3)

La catedra pide un **tablero de gestion** con tareas y responsables, ademas del
repositorio. Aca tenes dos opciones. Elegi UNA. Recomendada: **GitHub Projects**
porque queda al lado del repo y el profe ya lo ve.

---

## OPCION A - GitHub Projects (recomendada)

1. Entra a tu repositorio en **github.com**.
2. En la barra de arriba del repo, toca la pestana **Projects**.
3. Toca el boton verde **New project**.
4. En la ventana que aparece, elegi la plantilla **Board** (tablero de columnas).
5. Ponele un nombre: `Sprint 3 - Infeccion Escape del Carmen` y toca **Create**.
6. Vas a ver 3 columnas: **Todo**, **In Progress**, **Done**.
7. Para cargar una tarea: en la columna **Todo** toca **+ Add item**, escribi el
   titulo de la tarea y toca **Enter**.
8. Para asignar responsable: abri la tarjeta (click en ella), a la derecha toca
   **Assignees** y elegi al companero.
9. Para mover una tarea: arrastrala de **Todo** a **In Progress** y despues a
   **Done** cuando este lista.

## OPCION B - Trello

1. Entra a **trello.com** y toca **Log in** (o **Sign up** con el mail del grupo).
2. En el inicio, toca **Create a board** (boton con un +).
3. Ponele nombre `Infeccion - Sprint 3` y toca **Create**.
4. Crea 3 listas tocando **Add a list**: escribi `Por hacer`, `Haciendo`, `Hecho`.
5. En `Por hacer` toca **Add a card**, escribi la tarea y toca **Add card**.
6. Abri la tarjeta y toca **Members** para asignar al companero (antes invitalos
   con **Share** -> escribir su mail -> **Send invitation**).
7. Arrastra las tarjetas entre listas segun avancen.
8. Para que el profe lo vea: toca **Share** -> **Create link** -> copia el enlace
   y pegalo en el entregable (junto al enlace del repo).
